# The Excuse My Agent Gave Me

> "I'm sorry — I hallucinated a meeting where you moved the deadline to next week, so I spent today celebrating the extension."

`main.ts` validates the one-line excuse (1–200 characters, single line, no newline) and writes it as `entry.txt` to `MAKEFUN_OUTPUT_DIR` (default `/output`), with no trailing newline.
